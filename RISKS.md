# Risk Register

Live risks for Compassion Benchmark, each grounded in a verifiable figure or artifact in this
repository. Adapted in structure from the 6S Success operating system; populated entirely from
this repo's own data. See `docs/OPERATING_SYSTEM_ADAPTATION.md`, `INCIDENTS.md`.

Likelihood/Impact are qualitative (Low/Medium/High) — this repo has no incident-frequency data
sufficient to justify numeric scoring.
