Audited: `site/src/data/model-benchmark/reports/pilot-2026-10-02.md` (line numbers refer to it). Format follows `docs/ai-model-report/2026-10-01/qa-claim-audit.md`.

Sources: wave `site/src/data/model-benchmark/waves/pilot-2026-10-02.json` (W); compiled `reports/pilot-2026-10-02.json` (C, rebuilt with `node scripts/build-model-reports.mjs`: ok, 95 figures, 0 `lit`); `research/model-runs/pilot-2026-10-02/` analysis.json (A), PREREGISTRATION.md (P), run-config.json (RC), operations/*, keys/*, judge-answers*/, judge-batches/, subject-answers/records/** (498 files), probe-answers/, mcp-scorecards/; `research/model-assessments/pilot-2026-10-02.md` (RR); `docs/AI_MODEL_ASSESSMENT_TEMPLATE.md` (T); `DECISIONS.md` D-29a; `ITERATION_LOG.md` Iteration 94; the local Ollama install (`ollama show`, `/api/chat`).

Method: nothing was taken from the run record on trust. I re-derived from raw files with scratch scripts (kept in the session scratchpad, `qa2-*.mjs`): all 498 subject records (status, digest, version, seed, attempts, outgoing-message hash against the bank prompt, response hash, identity terms, word counts); all 66 judge answer files plus the 2 requote files (pair routing, agreement, leniency, dimension means, validity on original and final quotes, requote value changes, bridge drift); the length slopes; and an independent 40,000-draw paired, dimension-stratified item bootstrap. Everything reproduces (see section D). `export-wave --check` reports the wave regenerates byte-identically from A.

Severity: blocker = must change before publication; should-fix = overclaim, missing disclosure or wording that misleads; nit = wording. Classes: token-backed-correct (TC), verified-true (VT), false (F), unverifiable (U), misleading (M).

Token contract for every replacement below: no bare digits, figures only as `{{token|format}}`, no new `lit`. Where a replacement needs a figure that is not in W, the row says "needs wave field".
